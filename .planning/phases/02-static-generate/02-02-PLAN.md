    let mut out = String::with_capacity(32_000);

THIS TASK implements `emit_header`, `emit_recycle`, `emit_gear_bands`, `emit_flask_charm_bands`,
and the shared `emit_style_actions`. Leave `emit_currency_sections` as a stub (`fn ... {}`) so the
crate compiles; Task 2 fills it.

**Single canonical action order** — `emit_style_actions(out, style)` emits ONLY the present
(Some / true) fields, in EXACTLY this order (D-03, from RESEARCH §"Canonical Action Order"):
1. `PlayEffect {color}` (+ ` Temp` if beam.temp) — if `beam` present
2. `MinimapIcon {size} {color} {shape}` — if `minimap` present
3. `SetTextColor R G B 255` — if `text` present
4. `SetBackgroundColor R G B 255` — if `background` present
5. `SetBorderColor R G B 255` — if `border` present
6. `SetFontSize N` — if `font` present
7. `CustomAlertSound "{custom}" {vol}` if `sound.custom` present, ELSE `PlayAlertSound {id} {vol}`
   if `sound.id` present — if `sound` present
8. `DisableDropSound` — if `disable_drop_sound == true`

Use `writeln!(out, ...).unwrap()` (String's fmt::Write is infallible). All color/minimap/beam
values render via an `as_filter_str()` helper on `FilterColor` and `MinimapShape` (match each
variant to its exact PascalCase string — e.g. `FilterColor::Pink => "Pink"`,
`MinimapShape::UpsideDownHouse => "UpsideDownHouse"`). Indent block body lines with two spaces.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| config.json / currency.json → emitter | Local hand-edited inputs; hardened loader |
| emitter String → --output file path | CLI writes generated text to a user-supplied path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03 | Tampering | --output path write in cmd_generate | mitigate | Write exactly the user-supplied `--output` path via `std::fs::write` (no shell, no path concatenation from input, no traversal expansion); default is the repo-root universal.filter. The path is operator-controlled on an offline CLI — write only where instructed, surface fs errors via miette rather than panicking |
| T-02-04 | Information disclosure | generated filter contents | accept | Output is a loot filter derived from local committed config; no secrets involved |
| T-02-05 | DoS | unbounded output size | accept | Output bounded by config/currency size (~31 KB); single local run |
</threat_model>
