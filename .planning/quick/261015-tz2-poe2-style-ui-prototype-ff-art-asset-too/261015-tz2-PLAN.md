# PoE2-style UI prototype: ff-art asset tool, skin module, ff-proto binary

Goal: a runnable prototype (`ff-proto`) that shows PoE2-styled UI elements built from the
game's own Options-window art, ahead of a UI-redo milestone. The real `ff` overlay does not
change in behaviour or look. Design approved by the author (no open questions).

## Task 1 -- `tools/ff-art` (dev tool, own workspace)
- Separate crate with its own `[workspace]`; never a dependency of `ff`. Uses the
  `poe_data_tools` library (nightly) to read `Bundles2` read-only, `image` + `image-extras`
  (DDS) to decode, `resvg` for the SVG.
- Committed manifest `assets/poe2/manifest.toml` (path, out, prefer_4k, trim, crop, clear,
  fonts, ferris section). Subcommands: extract (default), list, dump, sheet, info, ferris.
- Ferris background: SVG -> edge-detected pale white line art on a transparent 1200x2000 PNG.
- Run once; commit outputs. Verify: files written, `cargo build` of the main crate untouched.

## Task 2 -- `src/skin/` (pub, reusable)
- palette, fonts (Fontin SmallCaps/Regular + Cinzel kept), embedded textures (`include_bytes!`,
  LINEAR + mipmaps), nine/three-slice painters (pixel-snapped, half-texel inset),
  widgets: ff_frame, ff_header, ff_tabs, ff_section, ff_row, ff_check, ff_slider,
  ff_dropdown, ff_button, ff_close, ff_scroll (game-art scrollbar), plus a DPI-correct
  left-dock helper. Unit tests for pure geometry + headless widget interaction.
- Verify: `cargo test` passes, `cargo fmt --check` clean, `src/overlay/*` untouched.

## Task 3 -- `src/bin/ff-proto.rs`
- Left-docked 660px, full work-area height, borderless; static Ferris background; header with
  title + close; RULES / CONFIG / ECONOMY tabs; framed scrollable fake content; bottom bar with
  status + REVERT / RELOAD / APPLY. `--screenshot <png>` renders, saves and exits.
- Verify: run with `--screenshot`, look at it, iterate; final screenshot saved here.

## Task 4 -- docs
- README section (GGG disclaimer verbatim, art/fonts/Ferris credits, how to run ff-art and
  ff-proto), CLAUDE.md layout rows, CHANGELOG [Unreleased], assets/ASSETS.md rows.
