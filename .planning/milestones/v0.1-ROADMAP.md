# Milestone v0.1: Initial Release

**Status:** ✅ SHIPPED 2026-05-28
**Phases:** 1-4
**Total Plans:** 14

## Overview

The first shippable FerrisFilter — a Rust CLI that compiles a human-editable policy model into a
Path of Exile 2 loot filter (`generate`) and fetches live currency prices from poe.ninja (`sync`).
Delivered across four phases: a Cargo/serde foundation, a deterministic byte-for-byte generator,
a price-driven tiering layer, and the live `sync` pipeline. An `install` subcommand and an
early-league price fallback landed alongside.

## Milestone Summary

**Stats:** 4 phases · 14 plans · ~4,970 LOC Rust · 127 commits · 2026-05-21 → 2026-05-28.

**Key Decisions:**

- Two subcommands (`generate` + `sync`); `sync` fetches raw prices only, `generate` does all conversion + tiering (network/IO separated from deterministic logic).
- Separate input files: `config.json` (human policy) · `tiers.json` (cutoffs) · `prices.json` (synced).
- Chaos as the internal reference unit; cross-rates derived from the first three `prices.json` anchors (Exalt/Chaos/Divine) — later generalized to read the anchors in whatever unit they're quoted in.
- `filter-model.json`/`config.json` is the executable spec; byte-for-byte reproduction locked by an insta snapshot + `artifact_guard` test.
- Price-tier valuable uniques only; untracked uniques/gems/jewels/etc. fall through to game default.
- Milestone git branching (`milestone/{slug}`), squash-merge to `main` + annotated tag on completion.

**Issues Resolved:**

- poe.ninja PoE2 API surface (the project's one external unknown) resolved via spike: exchange + stash/item overview endpoints, plural `type` values, league index-state resolution.
- `sync --standard`/`--hc` hoisted onto the `sync` command (clap parse fix, d15e82e).
- Generalized cross-rate derivation so the orbs can be quoted in any single unit (enables the exalt-denominated early-league fallback).

**Technical Debt / Deferred:**

- Live softcore no-flag `sync` happy path can't be demonstrated while no challenge league is active ("Fate of the Vaal" ended); the tool fails safe. Re-confirm when a new league launches. (Verification + UAT signed off as working on 2026-05-28 via the live `--standard` run.)
- Lenient-parse guard for Standard-league unique endpoints returning a different/empty shape (`UniqueSanctumRelics` missing `core`) — non-blocking.
- Consider a no-flag `sync` fallback/hint to `--standard` when no challenge league is active.
