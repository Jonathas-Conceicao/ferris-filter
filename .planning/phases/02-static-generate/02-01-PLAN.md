Define the enum above `BandShow`:

```rust
#[derive(Debug, Clone, Deserialize, Serialize, PartialEq)]
pub enum RarityRule {
    #[serde(rename = "any rarity")]   Any,
    // NOTE: config.json uses TWO strings that mean "show Rare": weapons use "Rare only",
    // otherGear uses bare "Rare". Both emit the identical `Rarity == Rare` condition
    // (verified against universal.filter L79 otherGear and L48 weapons), so they collapse
    // to ONE variant via a serde alias. Serializing yields "Rare only".
    #[serde(rename = "Rare only", alias = "Rare")] RareOnly,
    #[serde(rename = "Magic + Rare")] MagicPlusRare,
    #[serde(rename = "Magic")]        Magic,
    #[serde(rename = "Quality only")] QualityOnly,
}
```

Change `BandShow` fields `weapons`, `all_armour`, `other_gear`, `flasks_charms` from
`Option<String>` to `Option<RarityRule>`. Change `ArmourShow.rarity` from `String` to `RarityRule`.
Add a small inline test `rarity_rule_variants_roundtrip` that asserts
`serde_json::from_str::<RarityRule>(r#""Magic + Rare""#).unwrap() == RarityRule::MagicPlusRare`
and the reverse serialization yields `"Magic + Rare"`. Add a test `rare_alias_maps_to_rare_only`
asserting `serde_json::from_str::<RarityRule>(r#""Rare""#).unwrap() == RarityRule::RareOnly`
(the otherGear value). Add a negative test
`rarity_rule_rejects_unknown` asserting `serde_json::from_str::<RarityRule>(r#""Legendary""#)`
is `Err`. Do NOT add `deny_unknown_fields` to the enum (not applicable). Confirm the exact
strings against config.json before writing the renames — they must match byte-for-byte. The SIX
distinct strings present are: "any rarity", "Magic + Rare", "Rare only", "Rare" (otherGear,
bands 6-25 & 26-45 — aliased to RareOnly), "Magic", "Quality only". A `config_parses_real_file`
test MUST confirm the real config.json deserializes after this change (catches the otherGear
"Rare" case end-to-end).
