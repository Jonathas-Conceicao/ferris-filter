New contract this plan defines (later plans rely on these exact names):
- `pub const RULE_LINE: &str` = exactly 80 `#` characters (a literal; a unit test asserts length 80 and all `#`).
- `pub const SECTION_KEY: &str = "section";` `pub const BEGIN_KEY: &str = "economy-begin";`
- `pub const BEGIN_LINE: &str = "# ff:economy-begin Economy (generated by FerrisFilter, do not edit)";`
- `pub fn is_rule_line(text: &str) -> bool` — `text.trim_end()` has length >= 3 and is only `#` (lenient read; writers always use `RULE_LINE`).
- `pub fn banner_starts(lines: &[Line]) -> Vec<usize>` — 0-based index of the first rule line of every banner, scanned top-down greedily: lines i, i+1, i+2 form a banner when `is_rule_line(i)`, line i+1's `ff_marker()` key is `SECTION_KEY` or `BEGIN_KEY`, and `is_rule_line(i+2)`; after a match the scan resumes at i+3 (so `###/a/###/b/###` is one banner `a` plus comments).
- `#[derive(Debug, Clone, PartialEq, Eq)] pub enum BannerKind { Section, Economy }`
- `#[derive(Debug, Clone, PartialEq, Eq)] pub struct Banner { pub start: usize, pub kind: BannerKind, pub name: String }` — `start` = first rule line; name = the marker value trimmed (empty or absent -> `"Section"` for sections, always `"Economy"` for the economy banner).
- `pub fn banners(doc: &Document) -> Vec<Banner>` in file order.
- `SectionSpan { begin, end }` keeps its name; NEW meaning: `begin` = economy banner start (first rule line), `end` = EXCLUSIVE end = start of the next banner after it, or `lines.len()`. Add `impl SectionSpan { pub fn body_start(&self) -> usize { self.begin + 3 } }`. The existing caller idiom `h > s.begin && h < s.end` (header strictly inside) stays correct.
- `SectionError`: remove `EndWithoutBegin`, `BeginWithoutEnd`, `EndBeforeBegin`, `DuplicateEnd`; add `IncompleteBanner { line: usize }` (1-based) with message: "economy section is damaged: `# ff:economy-begin` on line {line} is not inside a banner (a line of `#` above and below it); this is the old one-line marker or a damaged banner, fix it by hand, nothing was written". Keep the other variants.
</interfaces>
