<objective>
Give the library a public editing and saving surface for the two files the CONFIG tab owns:
`styles.json` (StyleSet mutators + renderer) and `tiers.json` (renderer + unit label). Today
`StyleSet` can only be loaded and validated: `insert`/`remove` are `#[cfg(test)] pub(crate)` and
nothing writes `styles.json` (RESEARCH Summary gap 1).

Purpose: CONF-02 (add/edit/delete named styles, built-ins undeletable) and CONF-03 (tier cutoffs
saved back to `tiers.json`) need a pure, tested model layer before any overlay code exists.
Output: new public `StyleSet` API, `StyleNameError`, enum `ALL` lists, `render_styles`,
`render_tiers`, `Unit::as_str`, and their tests.
</objective>
