## Trust Boundaries

| Boundary | Description |

| user click -> keystrokes into the game | The only path that injects input; must be exactly one command per click |
| ff -> system clipboard | User's clipboard is overwritten briefly and restored |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-12 | Tampering | `WinSink` VerifyForeground | mitigate | `game_is_foreground` checked before clipboard write, before the first Enter, before select-all/paste and before the final Enter; any failure aborts via `chat::execute` so no key reaches another app |
| T-23-13 | Information Disclosure | `WinSink` RestoreClipboard | mitigate | Restore only when `clipboard_sequence()` still equals our write's number (never overwrite something the user copied meanwhile); saved text dropped after restore, never logged or shown |
| T-23-14 | Repudiation / ToS | `run_apply` | mitigate | Send only on a Written RULES Apply via `chat::decide`; `ReloadSend::start` refuses while in flight; no retry, timer or queue; CONFIG Apply path has no hook |
| T-23-15 | Denial of Service | egui frame | mitigate | All sleeps run on the worker thread; the frame only polls `try_recv`; repaint requested by the worker's notify |
| T-23-16 | Tampering | ff-settings.json | mitigate | Saved through the existing atomic `settings::save`; unknown keys preserved; save error surfaced in `config_message` |
| T-23-SC | Tampering | dependencies | accept | No new crates or features in this plan |
</threat_model>
