# Phase 34 — UI Design Contract

> Visual and interaction contract for the ECONOMY and ABOUT tabs. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Rust egui/eframe overlay: "px" means egui logical points (pt); the design system is the in-repo `src/skin/`. This spec EXTENDS `33-UI-SPEC.md` / `32-UI-SPEC.md` / `30-UI-SPEC.md`: palette, Fontin sizes 14/15/17/21, `ROW_PAD` 10, `ROW_HEIGHT` 34, 535pt content width (517 inside the scrollbar reserve), `LABEL_COL_W` 128 / control column 353 for `ff_field_row`. Where silent, Phase 33/30 applies. NO new colours, sizes or faces. ONE new art file (`assets/ui/ferris-about.png`). Sources: 34-CONTEXT.md (locked), CLAUDE.md, memory note "Overlay UI not texty", `src/bin/ff-proto.rs` (`economy_tab`, `about_tab`), `src/overlay/shell.rs` (`economy_tab`, `last_sync_text`, `tab_markers`, `bar_state`), `src/skin/widgets.rs`. Items marked "(Claude's decision)" were decided here (non-interactive run).

## ECONOMY tab

Focal point: the SYNC ECONOMY button (the only gold-framed action on the page). Everything is inside one `ff_scroll_area("economy")`; content width 517pt; row heights 34; zebra via `row_background` by index restarting at 0 in each section.

Top to bottom:

| # | Element | Contract |
|---|---------|----------|
| 1 | Section `Economy` | `ff_section` (SmallCaps 21 `HEADING`) |
| 2 | `League` | `ff_row`, value `regular(15)` `VALUE`: `sync::OVERLAY_LEAGUE` (e.g. `Forbidden Rites`). Tooltip on the label: `Pinned in this build.` |
| 3 | `Last sync` | value = relative text (rules below); tooltip on the value = exact local `YYYY-MM-DD HH:MM` (existing `last_sync_text`) or nothing when never synced |
| 4 | `Priced items` | thousands-separated count of priced entries in `prices.json` (e.g. `1,284`); `0` shows `0` (not a dash) when the file is missing |
| 5 | `Price source` | `Live prices` when `prices.json` is present and non-empty; `Fallback prices` (colour `pal::WARN`) when it is missing or empty. Tooltip: live: `prices.json from the last sync.`; fallback: `No prices.json yet. Using the built-in early-league prices. Sync to get live ones.` |
| 6 | gap | 16pt |
| 7 | Sync line | `ff_button_ex("Sync economy", 180, enabled && !syncing)`, centred; while syncing the caption is `Syncing…` and it is disabled. Disabled with no app root: tooltip is the existing missing-app-root message. Result of the sync shows only in the shared status line (existing; names the league). No inline result text |
| 8 | gap | 16pt, then section `Economy section` |
| 9 | Section toggle row | one `ff_row` (index 0), label `Filter section` (SmallCaps 17 `LABEL`, tooltip: `The economy blocks FerrisFilter writes at the end of the filter. Added and removed by Apply.`), right-aligned `ff_button_ex` 188pt whose label follows state: `Add economy section` when absent, `Remove economy section` when present (danger red caption on Remove). Value text to its left: `N locked blocks` (`regular(14)` `MUTED`, only when present and N known; tooltip `Rules inside the section cannot be edited.`) |
| 10 | gap | 16pt, then section `Tiers` |
| 11 | TIERS editor | the existing editor from `config_view.rs`, moved unchanged in behaviour: same rows, inline validation (red `INVALID_RED` outline + tooltip), same ConfigAction/edit model. Re-skinned only to the lines/gaps above if it still uses legacy widgets; no new fields |

Relative-time wording for Last sync (Claude's decision), from `now - prices.json mtime`:

| Age | Text |
|-----|------|
| no file | `Never` |
| < 1 min | `Just now` |
| < 60 min | `{n} min ago` |
| < 24 h | `{n} h ago` |
| < 14 days | `{n} d ago` |
| otherwise | the exact `YYYY-MM-DD` date |

The text is computed at draw time; request a repaint after 60 s while ECONOMY is visible so it does not go stale. Never negative (clock skew clamps to `Just now`).

Add / Remove behaviour:

- States: absent -> `Add economy section` (enabled when a filter is loaded, root ok, nothing changed on disk); present -> `Remove economy section`; damaged markers, no filter or load error -> button disabled with tooltip `Fix the filter first.` (the status line carries the real reason).
- Add: in-memory only (`stage_add_economy`), appends the begin-only banner at the END of the file (Phase 32 format). The row flips to `Remove economy section` immediately; marks RULES/filter unapplied; written by the shared Apply; undone by Revert. No popup.
- Remove: opens the existing `Remove economy section?` popup (`PopupData::RemoveEconomy`, [Remove (danger) / Keep], Escape/backdrop = Keep, copy unchanged). Confirm stages the removal (`stage_remove_economy`), same Apply/Revert model.
- Staged but unapplied state shows as the label of the current state (no extra badge); the unapplied indicator in the status line and tab markers carry it.

Revert / Apply on ECONOMY: the shared bottom bar. Revert is enabled when the filter staging or tier edits are dirty (it was `false` for ECONOMY; now follows the combined dirty state, and for tier edits reuses the existing `Discard config changes?` popup). Apply uses the combined decision plus tier-error gating (`APPLY_BLOCKED_TOOLTIP` when tier cutoffs are invalid) exactly as CONFIG does today.

Tab markers: `tab_markers` gains tier ownership. ` *` shows on ECONOMY when tier cutoffs have unapplied edits; CONFIG shows it for style/filter-choice edits only (no longer for tiers); RULES keeps filter edits including staged economy add/remove. ABOUT never. Active tab markers behave as today.

RULES changes (Claude's decision, locked by CONTEXT): delete the `x` on the expanded Economy header, delete the `Add economy section` footer button and the SYNC ECONOMY button in the RULES footer. The Economy divider stays as a display-only collapse/expand header with the read-only locked rows and its `+ N locked rule blocks (economy)` summary text; its tooltip gains `Add or remove it in the ECONOMY tab.` CONFIG loses its TIERS section (CONFIG: Filter, Styles only).

## ABOUT tab

Focal point: the happy Ferris image. Non-scrolling page, centred column, vertically laid out in the 660pt window's page frame; use the available rect height so the footer pins to the bottom (as `ff-proto` does with `area.max.y`). No section headings, no rows, no frames.

Top to bottom (all centred horizontally; `item_spacing.y` 0, explicit gaps):

| # | Element | Contract |
|---|---------|----------|
| 1 | top pad | 16pt |
| 2 | App name | `FerrisFilter`, `small_caps(21)`, `pal::HEADING`. (The prototype's 36 is dropped: 21 is the largest allowed size.) |
| 3 | gap 4 + description | `Loot filter editor for Path of Exile 2`, `regular(15)`, `pal::LABEL`, single line |
| 4 | gap 16 + Ferris | `assets/ui/ferris-about.png` drawn 112pt wide (height by aspect, about 75pt), centred, tint WHITE (original orange colours), LINEAR + mipmaps like the other skin textures, loaded in `skin` with `include_bytes!`; decorative, accessible name `Ferris the crab`, no tooltip, not clickable |
| 5 | gap 8 + Version | `Version {env!("CARGO_PKG_VERSION")}`, `regular(14)`, `pal::MUTED` |
| 6 | gap 4 + GitHub link | `github.com/Jonathas-Conceicao/poe2-myfilter`, `regular(15)`, `pal::GOLD`, `ui.hyperlink_to` to `REPO_URL` (opens the system browser; pointing-hand cursor; underline on hover as egui does); tooltip `Open the repository in your browser.` Reuse the `REPO_URL` constant (move it from `ff-proto.rs` to the library so both binaries share it) |
| 7 | gap 16 + Divider | the existing title underline art (`skin.title_underline`, as in `ff-proto`) 3pt tall, 80% of content width, `Color32::from_white_alpha(110)`, centred |
| 8 | flexible empty space | takes all remaining height down to the footer block; nothing is drawn in it |
| 9 | Footer block (pinned to bottom, 16pt above the page frame edge, wrapped, centred, max width 480pt) | Disclaimer first, then credits, 16pt apart (below) |

Footer text (Claude's decision on sizes/colours; 14 is the smallest allowed size, so "smaller" is 14 versus 15 and the dimmer colour):

| Line | Size / face | Colour | Copy |
|------|-------------|--------|------|
| Disclaimer 1 | `regular(15)` | `pal::LABEL` | `This product isn't affiliated with or endorsed by Grinding Gear Games in any way.` |
| Disclaimer 2 | `regular(15)` | `pal::MUTED` | `The game art and fonts belong to their owners. FerrisFilter is a free third-party tool for Path of Exile 2 players.` |
| gap | 16pt | | |
| Credits | `regular(14)` | `pal::MUTED` | three centred lines, 4pt apart: `Game art and fonts: Grinding Gear Games` / `Fontin typeface: exljbris` / `Ferris the crab: Karen Rustad Tölva, public domain` |

The credits come after the ownership disclaimer so third-party credit is not read as ownership of the tool. Wrapped text uses `Label::wrap` with `Align::Center`; it must not clip at 660pt (max 480pt wide means 2 lines for each disclaimer sentence).

Bar on ABOUT: shared bottom bar unchanged (Revert disabled, Reload/Apply as the combined state). Window dock, keyboard focus order: GitHub link is the only focusable control on the page.

### Art pipeline

- `tools/ff-art` `ferris` subcommand gains a colour variant (e.g. `ferris --colour` or a second manifest-like output) rendering `assets/ferris/rustacean-flat-happy.svg` via `resvg` in its ORIGINAL colours (no pale tint, no alpha fade) to `assets/ui/ferris-about.png`: 336 px wide (3x of 112pt for crisp mipmapped scaling at 100-200% DPI), transparent background, tight crop to the artwork, under 100 KB. Committed; `assets/ui/ferris-bg.png` is unchanged. CLAUDE.md `assets/ferris/` row gains the new PNG; Ferris credit stays Karen Rustad Tölva, public domain.
