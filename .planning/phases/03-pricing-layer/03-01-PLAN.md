<objective>
Extend the `prices.json` schema with `class` and `category` (D-03) and generate the seeded
`prices.json` from `currency.json` (D-09) via a one-time migration binary. After this plan
`prices.json` is the committed value source the rest of Phase 3 reads from; `currency.json`
remains in-repo only as the migration source.

Purpose: lay the data foundation for price-driven tiering (TIER-01/02/03). The seed values are
chosen so the pricer reproduces every curated tier exactly (non-reference bases at tier
lower-bound), except the three reference orbs which carry realistic values and deliberately
re-tier (handled and verified in plan 03/04).
Output: a modified `PriceItem` schema, a `src/bin/seed_prices.rs` migration tool, and the
regenerated committed `prices.json`.
</objective>
