## Interface from Plan 22-01 (src/overlay/instance.rs)

- `pub fn acquire() -> Option<Guard>`: `Some` = this is the only instance, keep the Guard alive until
  exit; `None` = another instance was signalled (and, on a 2 s timeout, the not-responding
  MessageBox was already shown) -- return `Ok(())` from `launch()`.
- `impl Guard { pub fn take_show_request(&self) -> bool; pub fn ack(&self); }` -- zero-timeout poll
  of the auto-reset show event; ack sets the event the second instance waits on.
- `Guard` is not `Send` (raw HANDLEs); it is created and used on the main thread only, like the
  tray handles.
