Decisions (author's place):
- Decision (author's place): the installer also puts `LICENSE.txt` (the repo `LICENSE`) next to
  `ff.exe` in `{app}`. GPL-3.0 asks that the license accompany object code; it is not a program,
  so "installs only `ff.exe` (CLIs are dev tools)" still holds. No license wizard page.
  Confirm at 40-07: the author confirms this in the installer UAT (step 8); if they say drop it,
  40-07 removes the `[Files]` LICENSE entry before 40-08.
- Decision (author's place): the "Launch FerrisFilter" finish entry keeps `skipifsilent`
  (standard). A `/SILENT` update therefore does not restart `ff`; Phase 41 decides how its
  updater relaunches (handoff note in the SUMMARY).
- Decision (author's place): no `AppMutex` (it nags before `--quit` can run); `CloseApplications=yes`
  stays as the Restart Manager backstop with `RestartApplications=no` so `ff` is never started
  twice.
- Decision (author's place): AppId GUID is fixed now as `{1FDA92ED-8F71-4558-B482-3EC93A7AA550}`
  (written `{{1FDA92ED-8F71-4558-B482-3EC93A7AA550}` in the .iss). It must never change (Inno keys
  the HKCU uninstall entry on it) and differs from the instance-name GUID in instance.rs.
- Decision (author's place): if the user leaves the Unapplied changes popup open during uninstall,
  `[UninstallRun] ff.exe --quit` returns 1 after its timeout and Inno reports it could not remove
  ff.exe (research Pitfall 12); accepted, no uninstall Retry loop (it would run before the
  uninstall confirmation).
- Local-only switch: `FF_SKIP_INSTALLER=1` makes package.sh skip ISCC (prints a loud warning;
  SHA256SUMS then lists the zip only). CI never sets it, and release.yml's assets gate requires all
  three files.
