## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user click -> popup -> pending set | a confirmed reset replaces built-in styles or tier cutoffs in memory |
| Apply -> styles.json / tiers.json | the existing guarded all-or-none write |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-38-13 | Tampering | accidental reset of the user's styles/tiers | mitigate | button only arms; red `Reset` needs an explicit click; Escape/outside = Keep; result is a pending edit Revert undoes; customs kept (tests) |
| T-38-14 | Tampering | reset writing files directly | mitigate | handlers call only the in-memory `reset_styles`/`reset_tiers`; the only writer remains Apply with its changed-on-disk guard |
| T-38-15 | Elevation of Privilege | screenshot popup names | accept | debug-only mode, compiled out of release builds, already refuses non-temp homes |
