Decisions made in the author's place (recorded, not re-opened):
- Decision 1: a latest tag OLDER than the running build (dev/unreleased build) reads
  `Up to date (<running base version>)` with no date; an EQUAL tag reads
  `Up to date (<version>, released <date>)`. (This refines the UI-SPEC "same text" line, because
  the older release's date would mislead.)
- Decision 5: compare on `env!("CARGO_PKG_VERSION")` reduced to major.minor.patch (never
  `FF_VERSION`, which is `git describe` and not semver); installer file name derived from the
  validated tag; download only from the `browser_download_url` of the asset with the computed name,
  https only.
- Planner discretion (recorded): the accepted download URL is exactly
  `https://github.com/Jonathas-Conceicao/ferris-filter/releases/download/<tag>/<asset name>`,
  compared ASCII-case-insensitively; anything else is treated as a bad response. A `Ready` result
  with no `published_at` shows `<version> available` (UI-SPEC has no row for a missing date).
- Package legitimacy: `semver` 1.0.28 and `ring` 0.17.14 are already resolved in `Cargo.lock`
  (`ring` is compiled today through rustls), so this adds no new package to the lock, only two
  direct edges on the `ferrisfilter` package. The acceptance check proves no `[[package]]` entry
  is added. slopcheck was unavailable to the researcher (RESEARCH "Package Legitimacy Audit").

## Trust Boundaries

| GitHub API JSON -> parser | release JSON is untrusted input (tag, names, URLs, dates) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-41-01 | Tampering | installer file name / path | mitigate | `installer_name` builds the name from the semver-validated tag; API `assets[].name` is only compared, never joined onto a path (no traversal) |
| T-41-02 | Spoofing | `browser_download_url` | mitigate | `asset_url_is_trusted` accepts only `https://github.com/Jonathas-Conceicao/ferris-filter/releases/download/<tag>/<name>`; http and other hosts are rejected |
| T-41-03 | Tampering | `parse_sums` | mitigate | exactly 64 hex digits, exact name match, conflicting duplicates rejected; hash compare lowercase |
| T-41-04 | Spoofing | update URLs | mitigate | constants only, no env/CLI override in any build; tests use the `UpdateHttp` fake |
| T-41-05 | Denial of Service | response sizes | mitigate | `MAX_API_BYTES`, `MAX_SUMS_BYTES`, `MAX_INSTALLER_BYTES` caps defined here, enforced while streaming in 41-02 |
| T-41-SC | Tampering | Cargo dependency edit (semver, ring) | mitigate | both already resolved in Cargo.lock and `ring` already compiled via rustls; acceptance proves no new `[[package]]`; CI builds `--locked` |
