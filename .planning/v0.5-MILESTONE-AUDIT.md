## Integration

All key seams are wired: one Apply path (style rewrite, economy regeneration, guarded/backed-up
atomic write) shared by CLI and overlay; CONFIG writes feed RULES Apply and the economy; filter
switch resets the working copy and guard baseline; structural and line edits never touch the
economy span; `app_root` serves every input file and `ff-settings.json`; SYNC ECONOMY writes where
Apply reads; the instance gate precedes hotkey/tray/filter load. No v0.4 store references remain
in code. Warnings W1-W4 and orphaned exports are listed under tech_debt.

E2E flows: 14 PASS (open/no-op save, v0.4 migration, rule edits, structural edits, style apply
and edit, style delete, tier edit, outside edits, filter switch/create/relaunch, economy
add/remove, sync then apply, generate byte-identical, second launch); 1 not run headless
(460-block responsiveness, covered by Phase 19 UAT).
