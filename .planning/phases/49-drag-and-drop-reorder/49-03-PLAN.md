<feature>
  <name>Banner-aware multi-gap rule move</name>
  <files>src/filter/structure.rs, src/overlay/rules.rs</files>
  <behavior>
    structure.rs (`move_run_to`):
    - Single block moved down 3 rules and up 3 rules: order matches, comments above each moved block travel with it, blank-line separation preserved
    - Group of 2 and of 3 consecutive blocks moved as one region
    - `AfterBanner(k)` on a user banner: the block becomes the first block after the banner (blank lines right after the banner skipped, like divider.rs `hop`)
    - `BeforeBanner(k)`: the block becomes the last block of the section above (or of the preamble for the first banner)
    - `End` with an economy section: lands right above the economy banner; without one: at end of file
    - Last-unit-of-file cases: the moved block was last (no trailing blank) and a file without a final newline; CRLF file keeps CRLF on every line
    - No-op destinations (Before itself, Before the next block, BeforeBanner/End where the run already sits) return Ok with no change reported (a distinct `Ok(false)` or equivalent) and leave lines identical
    - Refused: `AfterBanner` on the economy banner (`EditError::SectionLocked`), any destination resolving inside/below the economy section, unknown block ids, a non-consecutive run
    - Round trip: `serialize` of the result contains exactly the same multiset of lines; block ids follow their blocks
    rules.rs (`MoveTo`):
    - Group moves as a unit and stays one rule (one row, same group id)
    - Follower id or economy id is refused by `dispatch` like other actions
    - Crossing a Continue rule (or moving a Continue rule) sets `moved`; a move crossing none clears a previously set flag
    - Dropping onto a collapsed section's AfterBanner puts the rule first in that section and leaves the section collapsed (rows rebuilt; the rule is hidden in the layout)
    - No-op gives `changed: false`; success gives `focus == Some(id)`
  </behavior>
  <implementation>
    In `src/filter/structure.rs` add `pub enum MoveDest { Before(BlockId), AfterBanner(usize), BeforeBanner(usize), End }` (doc: banner ordinals as used by divider.rs / `RowAction::RenameSection`) and `pub fn move_run_to(&mut self, run: &[BlockId], dest: MoveDest) -> Result<bool, EditError>` (true = changed) per research "Document / Model Map": resolve an insertion line in the old line vector (`Before`: `infos[pos].span.start`; `AfterBanner(k)`: banner start + 3, then skip blank lines, refuse the economy banner with `SectionLocked`; `BeforeBanner(k)`: banner start; `End`: economy banner start via `section::find`, else `lines.len()`), refuse any insertion line inside or after the economy section, take the region `infos[first].span.start .. infos[last].unit.end` (the same region `swap_runs` uses), detect no-op (insertion inside the region or at its start/end), splice, apply the same blank-line and final-terminator hygiene as `swap_runs` (`was_unterminated` handling), re-order `ids`/`expected` to the new block order and finish through `commit_structural` so a bad splice fails closed (`WouldReattributeLines`). Re-export `MoveDest` wherever `EditError` is re-exported from `crate::filter` if that is the pattern. Do not change `move_block`, `swap_runs`, `rule_step` or `move_section`.
    In `src/overlay/rules.rs` add `RowAction::MoveTo { id: BlockId, dest: MoveDest }` with a doc comment (one drop from the drag handle; the arrows' rules apply). Add it to `action_target` (returns `Some(id)`), to the block-action arm handled in `dispatch` beside `Move`, and to `coalesce_edits` as non-coalescing. Implement `fn move_rule_to(&mut self, id, dest) -> ActionOutcome`: `run = self.groups.members(id)`; compute `crossing` once = any block of the run `has_continue` OR any rule block strictly between the run and the insertion point in file order `has_continue` (banners do not count; hidden rules in collapsed sections do count, since they are crossed in file order); call `self.doc.move_run_to(&run, dest)`; on `Ok(true)` set `moved.insert(id)` if crossing else `moved.remove(&id)` (mirrors `move_rule` lines ~1777-1782, which also clears on a non-crossing step: judgement call recorded in SUMMARY), rebuild rows as other structural actions do and return `done_or(Ok(()), Some(id))`; on `Ok(false)` return an outcome with `changed: false` and no status; on `Err` return `done_or(Err(e), ..)`/`refused`. Keep `RowAction::Move`, `can_move_up/down` and `move_rule` and all their tests unchanged (still used by the fuzz test and section headers). Tests: structure.rs house-style unit tests and rules.rs unit tests per the behavior list; RED commit then GREEN commit (TDD plan).
  </implementation>
</feature>
