## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| poe.ninja -> worker -> UI | league names from the network become dropdown captions and the sync league |
| user click -> ff-settings.json | the league and price source are written immediately |
| UI -> sync worker | the league string reaches `run_sync_prices` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-39-12 | Tampering | sync started under Fallback or with an ended league via a stale click | mitigate | the click handler re-checks `price_policy() != ForceFallback` and `view.sync_league.is_some()`; the disabled button is not the only guard (tested) |
| T-39-13 | Tampering | league name used unsafely | mitigate | passed only to `run_sync_prices` -> `resolve_league_with_override` (name compare) -> reqwest `.query()` (URL-encoded); never a path or shell |
| T-39-14 | Denial of Service | UI thread blocked by the fetch | mitigate | `LeagueList::start` worker; fetch only on first Economy visit and refresh; refresh disabled while fetching |
| T-39-15 | Information Disclosure | unit tests or screenshot mode reaching poe.ninja | mitigate | `#[cfg(test)]` `fetch_leagues` twin returns Err; `!self.is_shot()` gate on both fetch call sites |
| T-39-16 | Repudiation | settings save failing silently | mitigate | `Could not save ff-settings.json: <err>` event, choice kept for the session (tested) |
</threat_model>
