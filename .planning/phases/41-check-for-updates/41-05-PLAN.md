## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ff process -> installer process | ff hands off to a downloaded executable at exit |
| user intent -> quit path | only an explicit Install click may lead to a spawn |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-41-20 | Elevation of Privilege | spawn of untrusted binary | mitigate | the only path to `spawn_installer` is the pending slot filled by `UpdateJob::shutdown`, which requires the click-time re-verification (existence + SHA-256) and the intent; tests cover Cancel, refused Apply and plain Quit leaving the slot empty |
| T-41-21 | Tampering | quit ordering | mitigate | spawn happens after `run_native` returns, after `begin_shutdown` released hotkey, tray and instance name; acceptance checks the line order and that app.rs never calls `spawn_installer` |
| T-41-22 | Repudiation / data loss | unapplied edits on install | mitigate | the click goes through `request_quit` and the unchanged Unapplied changes popup; no bypass |
| T-41-23 | Information Disclosure | temp-dir leftovers | mitigate | `shutdown()` deletes the work folder on any non-install quit, including during Downloading; the 24 h sweep is the backstop |
| T-41-24 | Spoofing | screenshot mode | accept | debug-only, compiled out of release; injects state with an empty installer path and never simulates an install click |
</threat_model>
