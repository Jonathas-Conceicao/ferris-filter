New contract (Plan 05 uses these exact names):
- `RuleRow` gains `pub section: Option<usize>` (ordinal of the containing banner; `None` above the first banner).
- `#[derive(Debug, Clone, PartialEq, Eq)] pub struct SectionRow { pub ordinal: usize, pub name: String, pub economy: bool, pub rules: usize, pub can_move_up: bool, pub can_move_down: bool }` — `rules` counts rules (a group run once).
- `#[derive(Debug, Clone, Copy, PartialEq, Eq)] pub enum ListEntry { Header { section: usize, collapsed: bool, matches: Option<usize> }, Rule(usize), EconomyRule(usize) }` — `section` indexes `sections()`, `Rule` indexes `rows()`, `EconomyRule` indexes `economy_rows()`; `collapsed` is the display state (always false while a query is active); `matches` is `Some(m)` only while a query is active.
- `WorkingFilter::sections(&self) -> &[SectionRow]` (projected: includes a synthetic economy row with `rules = blocks` when an economy add is staged, excludes economy when a remove is staged), `economy_rows(&self) -> &[RuleRow]` (empty while a remove is staged; read-only rows, `index` 0, `can_move_*` false), `entries(&mut self, query: &str, collapsed: impl Fn(&SectionRow) -> bool) -> Vec<ListEntry>`, `shadowing(&self) -> &HashSet<BlockId>`.
- `RowAction` gains `AddSection`, `AddSectionAbove(BlockId)`, `RenameSection { ordinal: usize, name: String }`, `RemoveSection(usize)`, `MoveSection(usize, Dir)`.
- `ActionOutcome` gains `pub section: Option<usize>` (ordinal of a section an action created).
- Status copy (exact): `Section added at the top. Press Apply to save it.`, `Section added above rule {index}. Press Apply to save it.`, `Section removed. Its rules joined the section above.`; refusal for economy targets: `The economy section is generated by FerrisFilter and cannot be changed here.`
