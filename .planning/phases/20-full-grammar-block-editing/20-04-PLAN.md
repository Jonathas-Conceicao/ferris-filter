<objective>
The egui-free library half of STYLE-03 / EDIT-06: one function that turns a `Style` into filter
action lines (shared by `generate` and the rule rewrite), and a pass over a `Document` that
rewrites every enabled, non-economy rule tagged `#ff:style <known name>` to that style's actions
and Show/Hide, reporting unknown style names instead of touching those rules.

Purpose: CONTEXT "Styles on rules": applying a style sets the rule's style actions and the style's
Show/Hide overrides the rule's own; on Apply a rule's style actions are rewritten from its style
whenever its `#ff:style` names a known style; hand edits on a styled rule are overwritten; an
unknown style is reported and the rule keeps its actions with no rewrite. Kept pure and public so
Phase 21's style editor can reuse it (20-RESEARCH cross-cutting note d).
Output: `emitter::style_action_lines`, new top-level module `src/styled.rs` (declared in lib.rs).
Placement decision: `src/styled.rs`, not `src/filter/`, because `filter` must not depend on
`models::config` (keywords.rs module doc: parsing must not depend on config types).
</objective>
