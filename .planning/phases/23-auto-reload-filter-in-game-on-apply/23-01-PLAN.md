<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| overlay -> another window's input queue | The step list decides what keystrokes may reach the game; a wrong target would put input into another app |
| ff-settings.json (user-editable file) -> Settings | Hand-edited JSON is untrusted input to the loader |
| overlay -> system clipboard | The user's clipboard contents are read and later written back |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-01 | Tampering | `execute` / `reload_steps` | mitigate | VerifyForeground precedes every Tap and the first Chord and precedes SetClipboard; `execute` stops at the first Err so no key follows a failed check (tests with FailingSink) |
| T-23-02 | Information Disclosure | clipboard save/restore | mitigate | RestoreClipboard runs exactly once whenever SaveClipboard ran, including every abort path; saved text is never logged or put in a message (tests) |
| T-23-03 | Tampering | `RELOAD_COMMAND` | mitigate | The injected text is a compile-time const; no settings or UI value can reach `SetClipboard` (ASVS V5) |
| T-23-04 | Repudiation / ToS | `ReloadSend::start`, `decide` | mitigate | At most one worker in flight; a second start returns false without running work; `decide` returns Busy; no retry, timer or queue exists |
| T-23-05 | Tampering | `settings::load` salvage | mitigate | Wrongly typed values are dropped individually with a warning; a salvaged filter name still passes `valid_filter_name` (no path escape) |
| T-23-SC | Tampering | dependency installs | accept | No new crate and no feature change in this plan |
</threat_model>
