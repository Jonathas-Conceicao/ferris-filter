| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-37-16 | Tampering | settings write on pick | mitigate | One settings::save (atomic, unknown keys kept); failure shown as a config_message and still applied for the session; never at launch |
| T-37-17 | Tampering | stale worker result | mitigate | Result applied only via poll() on the UI thread; one dialog at a time; Browse refused while a popup is pending or a pick is open; env-pinned folder ignores picks |
| T-37-18 | Denial of service | per-frame disk probing | mitigate | game_dir_missing computed only in refresh_filters / build |
