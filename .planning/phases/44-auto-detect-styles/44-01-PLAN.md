<objective>
Build the pure, egui-free core of Auto Detect: turn a rule's parsed action lines into a `Style`
(`StyleView::to_style`) and plan the whole run (which rules match an existing style, which new
`Custom Style N` styles to create, and the status text), with a table-driven test suite.

values, match order, naming, what stays Custom). Keeping it pure makes the equality traps
testable row by row before any UI or model wiring.

registered in `src/overlay/mod.rs`. No model mutation, no disk access.
