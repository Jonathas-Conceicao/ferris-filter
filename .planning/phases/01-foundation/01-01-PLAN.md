<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem → loader | `load_json` reads a local path that may be a malformed/adversarial JSON file |
| user argv → clap | `--output` path and subcommand args are user-controlled |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Denial of Service | `loader::load_json` on malformed JSON | mitigate | Use `serde_path_to_error::deserialize` returning `Err`; propagate with `?`; never `unwrap()`/`expect()` on file contents or parse results (ties to CFG-02). |
| T-01-02 | Denial of Service | deeply nested JSON input | accept | serde_json enforces a default recursion limit (128); inputs are shallow local policy files, not network data. Low risk per RESEARCH Security Domain. |
| T-01-03 | Tampering | `--output` path traversal | accept | Phase 1 does not write files (generate is a stub). Output path is an explicit user choice; revisit in Phase 2 when writing is implemented. |
</threat_model>
