## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| disk -> overlay | ff-state.json (league list, times, update replay fields) is untrusted local input |
| overlay -> poe.ninja / GitHub | fewer requests; cached league names are sent back as query params |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-46-06 | Tampering | cached league list from ff-state.json | accept | a forged name is only displayed and sent as the same `league=` query param a fetched one would be; poe.ninja re-resolves it (`run_sync_prices` fails loudly on an unknown league); list capped at 200 by throttle::record_leagues/load |
| T-46-07 | Spoofing | forged "up to date" replay | mitigate | cached_update requires update_app_version == env!("CARGO_PKG_VERSION") and expires after 3600 s; future times expire; a Ready result is never cached, so a newer release is always fetched and hash-checked by the existing update path |
| T-46-08 | Tampering | ff-state.json write | mitigate | written only via throttle::save (atomic temp+persist) into the resolved FerrisFilter root; never in screenshot mode; tests use tempdir homes only |
| T-46-09 | Denial of Service | throttle stuck on | mitigate | only real successes record (pending_real flags), fakes never extend the hour, failures never record (THR-03) |
| T-46-10 | Information Disclosure | CLAUDE.md | accept | documents behaviour only; no reset trick advertised (author rule) |
