## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-05 | Tampering | `encode` (List, CountNames, CustomSound) | mitigate | `EncodeError::BadText` for any `"` or control character (< 0x20, 0x7F) so a typed entry cannot close a quote, start a comment run on a new line or inject a second keyword; 20-01's candidate re-parse is the second gate |
| T-20-06 | Tampering | `decode` on unusual real-world forms | mitigate | Round-trip-or-raw: a structured value is used only when it re-encodes to identical tokens, so displaying a line can never rewrite it |
| T-20-07 | Information Disclosure | ClassCatalog | accept | Local single-user data, no secrets |
</threat_model>
