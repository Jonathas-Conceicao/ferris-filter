    - `pub fn write_guarded(path: &Path, loaded: Option<&[u8]>, new_bytes: &[u8]) -> Result<WriteOutcome, WriteError>`: delegates to the private core with the real `NamedTempFile::persist` and `std::thread::sleep`.
    - `pub const MAX_ATTEMPTS: u32 = 5;` base delay 50 ms doubling (50, 100, 200, 400).
    - Private core `fn write_guarded_with(path, loaded, new_bytes, persist: impl FnMut(tempfile::NamedTempFile, &Path) -> Result<std::fs::File, tempfile::PersistError>, sleep: impl FnMut(std::time::Duration)) -> Result<WriteOutcome, WriteError>`.

    Order inside the core (each failure leaves the target untouched; Pitfall 8: `loaded` is always the exact bytes read from disk, never a migrated buffer):
    1. `dest_dir = path.parent()` (empty parent means "."); must be `is_dir()`, else DestinationMissing. Never create directories.
    2. Re-read: `fs::read(path)`: Ok -> Some(bytes); NotFound -> None; other -> Unreadable. If that differs from `loaded` (Some/None mismatch or unequal bytes) -> ChangedOnDisk.
    3. If `loaded == Some(new_bytes)` -> Ok(Unchanged) (after the guard so a changed file still reports).
    4. If `loaded.is_some()`: `OpenOptions::new().write(true).create_new(true).open(backup_path(path))`; on success write_all the `loaded` bytes and sync, backup = Some(path); on `AlreadyExists` backup = None (never overwrite); any other error -> Backup error (abort before touching the target). Writing the guarded in-memory bytes, not `fs::copy`.
    5. `NamedTempFile::new_in(dest_dir)`, write_all, flush; loop up to MAX_ATTEMPTS: `persist(temp, path)`; on `Err(e)` where `e.error.raw_os_error()` is Some(5 | 32 | 33) and attempts remain: `sleep(delay)`, double delay, retry with `e.file`; on the last retriable failure return Busy; on a non-retriable error return Unwritable. Dropping the returned temp file deletes it (verify in tests that the dir holds only expected files afterwards).
    6. Doc comment: the TOCTOU window between step 2 and the rename is accepted (the guard catches edits made minutes apart by other tools, not millisecond races).

    Module header: no `println!`/`eprintln!`; every path is a parameter. Tests in `#[cfg(test)] mod tests` use `tempfile::tempdir()` only; simulate os errors with `std::io::Error::from_raw_os_error(n)` inside an injected persist closure that returns `Err(tempfile::PersistError { error, file })` (PersistError fields are public) for the first N calls and then calls `file.persist(path)`. Inject a sleep closure that records durations (no real sleeping in tests).
