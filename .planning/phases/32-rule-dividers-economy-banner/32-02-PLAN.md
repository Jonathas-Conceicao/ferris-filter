- `Settings.collapsed_sections: BTreeMap<String, BTreeMap<String, bool>>` with `#[serde(default, skip_serializing_if = "BTreeMap::is_empty")]`; outer key = bare filter name (as in `filter`), inner key = section name, value `true` = collapsed.
- `pub const ECONOMY_SECTION_KEY: &str = "ff:economy";` — a reserved key (the `ff:` prefix), so a user section named "Economy" never shares the real economy section's collapsed state;
- `impl Settings { pub fn section_collapsed(&self, filter: &str, name: &str, economy: bool) -> bool; pub fn set_section_collapsed(&self, filter: &str, name: &str, collapsed: bool) -> Settings; pub fn copy_section_state(&self, filter: &str, from: &str, to: &str) -> Settings }` — the two setters return a new `Settings` (same style as the existing `settings_with_filter` helpers in app.rs: compute `next`, save, then assign). `section_collapsed` returns the stored value, else `economy` (Economy defaults collapsed, user sections expanded). The economy section is looked up by `ECONOMY_SECTION_KEY`.
- `pub fn build_offsets_mixed(heights: &[f32], expanded: Option<(usize, f32)>) -> Vec<f32>` — like `build_offsets` but each entry has its own base height; `build_offsets(n, h, e) == build_offsets_mixed(&vec![h; n], e)`.
- New `FlagIcon` variants `ChevronRight`, `ChevronDown`, `Rename` painted in `paint_flag_icon`.
