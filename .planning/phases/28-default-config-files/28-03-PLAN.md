  `paths.styles`/`paths.tiers` with errors formatted `"<file name>: <reason>"` via `file_label`.
  `follow_disk` (~355) re-reads clean files whose bytes differ from `styles_bytes`/`tiers_bytes`.
  `styles_path()`/`tiers_path()` (~440) return the live paths (write targets — keep).

  `(Some(styles_base.to_vec()), ...)` unless overwrite. `safe_write` treats `Target.loaded: None` as
  "file must be absent" and on rollback removes a created file (safe_write.rs ~434, ~493) — so None is
  the correct guard for an absent live file. Test fixture `Fixture::new` (~427).

  `load_classes_at` (~223) passes `paths.styles` to `load_config`; `styles_mtime_at` (~314) stats the
