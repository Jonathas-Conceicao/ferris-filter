    Create `src/filter/tokenize.rs` (std only; `//!` doc: operates on borrowed text, returns byte
    ranges into the line, never rebuilds or trims stored text). Declare `pub mod tokenize;` in
    `mod.rs`.

    `pub enum Operator { Eq, EqEq, Bang, Ne, Lt, Le, Gt, Ge }` with `as_str()` returning the exact
    symbol. `pub struct TokenizedLine { pub indent: Range<usize>, pub keyword: Option<Range<usize>>,
    pub operator: Option<(Range<usize>, Operator)>, pub values: Vec<Range<usize>>, pub comment:
    Option<Range<usize>> }` — all ranges are byte offsets into the input line; quoted values include
    their quotes. `pub struct TokenError { pub col: usize, pub message: String }` (col 1-based).

    `pub fn tokenize(text: &str) -> Result<TokenizedLine, TokenError>`: scan with `char_indices` or
    byte checks on ASCII positions only (never slice on a non-char boundary). Steps: leading spaces
    and tabs = indent; if next char is `#` the rest of the line is the comment and keyword is None; if
    end of line, blank (keyword None); keyword = maximal ASCII-alphabetic run (if the first char is
    not alphabetic, TokenError "expected keyword"). Skip spaces/tabs; if the next chars are from the
    set `=<>!`, take the maximal run of those chars and match it exactly against `==`, `!=`, `<=`,
    `>=`, `=`, `!`, `<`, `>`; any other run (`=>`, `=<`, `<<`) is TokenError "unknown operator
    `{run}`". The operator may be glued to keyword or value. Then repeatedly: skip spaces/tabs; `#`
    starts the comment (range begins at the start of the whitespace run preceding the `#`); `"` starts
    a quoted value ending at the next `"` (no escapes; missing close quote is TokenError
    "unterminated quote"); otherwise a bare value up to whitespace, `#`, or `"`.

    `pub fn validate_shape(kw: &Keyword, line: &str, t: &TokenizedLine) -> Result<(), String>`:
    lenient per Pitfall 5 — never validate numeric ranges (font 1-45, volume 0-300) or names
    (BaseType / Class strings). Rules: Ops::None keywords reject any operator; NoValue requires zero
    values; Bool requires exactly one `True`/`False` (case-insensitive); Int requires >= 1 values each
    parsing as i64; QuotedList requires >= 1 value, bare or quoted; CountThenNames requires >= 1 value
    (if the first parses as integer it is the count and >= 1 more value must follow); Enum requires
    >= 1 values each in its list (case-insensitive); Rarity requires >= 1 values each in RARITIES;
    Sockets requires >= 1 values each matching digits then optional letters from RGBADW, or letters
    only; BoolOrName exactly one value; Rgba 3 or 4 integers; SoundId 1-2 values, first an integer or
    `None`, optional integer volume; CustomSound 1-2 values, first quoted or bare, optional integer
    volume; MinimapIcon either `-1` (optionally followed by colour/shape) or integer size + colour in
    COLOURS + shape in SHAPES; PlayEffect `None`, or a colour in COLOURS plus optional `Temp`;
    FontSize one integer; ImportPath one quoted value plus optional `Optional`.

    Unit tests implementing every behavior bullet (named `tok_*` and `shape_*`), plus
    `tok_never_panics_on_multibyte` feeding strings containing `é`, `—`, an emoji, and a lone `"`,
    `#` or `=` inserted at every char position.
