    Add a `Rarity` closed enum and a `RarityComparator` struct to config.rs.

    1. `Rarity` enum — closed vocabulary, ordinal-comparable:
    ```rust
    #[derive(Debug, Clone, Copy, Deserialize, Serialize, PartialEq, Eq, PartialOrd, Ord)]
    pub enum Rarity { Normal, Magic, Rare, Unique }
    ```
    (PartialOrd/Ord so Phase 6 can compare; JSON values are PascalCase matching variants.)

    2. `RarityOp` closed enum for the comparator:
    ```rust
    #[derive(Debug, Clone, Copy, PartialEq, Eq)]
    pub enum RarityOp { Eq, Gte, Lte }
    ```

    3. `RarityComparator` struct holding `op: RarityOp` and `rarity: Rarity`. It is authored in
    JSON as a COMPACT STRING (e.g. ">=Magic", "==Rare", "Rare", "<=Rare"), so implement a CUSTOM
    `Deserialize` and `Serialize` (do NOT derive them) that parse/emit the compact form:
    ```rust
    #[derive(Debug, Clone, Copy, PartialEq, Eq)]
    pub struct RarityComparator { pub op: RarityOp, pub rarity: Rarity }
    ```
    - Deserialize: deserialize a `String`, then parse. Strip a leading `==`, `>=`, or `<=`
      prefix (check the 2-char prefix first); a bare value (no prefix) means `Eq`. Trim
      whitespace around the remaining rarity word. Map the rarity word to the `Rarity` enum via
      serde_json::from_str on a quoted string OR a manual match ("Normal"/"Magic"/"Rare"/"Unique").
      On an unknown op token (e.g. "><") or unknown rarity word (e.g. "Legendary"), return
      `serde::de::Error::custom(...)` with a clear message naming the offending value, so the
      loader's `serde_path_to_error` surfaces the field path.
    - Serialize: emit the canonical compact string. Use "" prefix for Eq (bare), ">=" for Gte,
      "<=" for Lte, followed by the PascalCase rarity word. NOTE: because Eq serializes WITHOUT a
      prefix, the round-trip of an `==Rare` input becomes `Rare` — that is acceptable (still
      deserializes to the same value). Document this in a comment.

    Add a doc comment block above explaining the compact-string format and the bare==Eq rule.
  </action>
