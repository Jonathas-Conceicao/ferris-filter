<interfaces>
Flag → league (04-RESEARCH §SPIKE League Resolution):
| standard | hc | league chosen |
|----------|----|---------------|
| false | false | first economyLeagues where !hardcore && indexed (softcore trade) |
| false | true  | first economyLeagues where hardcore && url != "hardcore" (HC trade) |
| true  | false | economyLeagues where url == "standard" |
| true  | true  | economyLeagues where url == "hardcore" |

Price conversion (core.primary == "divine", the confirmed live case):
- chaos = primaryValue * core.rates["chaos"]
- exalt = primaryValue * core.rates["exalted"]
- div   = primaryValue
If core.rates is empty → skip that type (no conversion possible). The three reference orbs override:
Exalted Orb exalt=1.0, Chaos Orb chaos=1.0 by definition; compute the rest from rates.

Endpoints (constants):
- INDEX_STATE = "https://poe.ninja/poe2/api/data/index-state"
- OVERVIEW    = "https://poe.ninja/poe2/api/economy/exchange/current/overview"
  query: ("league", &league_name), ("type", &type_value)
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| poe.ninja → CLI | Untrusted economy + index-state JSON crosses into the process |
| CLI → prices.json | The committed output file rewritten atomically (consumed by `generate`) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-11 | Tampering | empty/malformed economy response → prices.json | mitigate | skip empty `lines`/`rates` per type; validate anchors present+non-zero + items non-empty BEFORE write; tempfile `persist` atomic (Pattern 4) |
| T-04-12 | Tampering | partial write on crash/power loss | mitigate | write temp in same dir then atomic rename (NamedTempFile::new_in + persist) — existing prices.json never half-written |
| T-04-13 | Information disclosure | response field parsing | mitigate | lenient serde, no `unwrap` on response fields (resolve_league/build_prices return Result); HashMap rate lookup is Option-guarded |
| T-04-14 | Tampering | wrong-currency tier corruption | mitigate | primaryValue converted via core.rates, never used raw (Pitfall 2); core.primary checked |
| T-04-15 | Spoofing / SSRF | overview/index URLs | mitigate | URLs are compile-time constants; league/type are validated values from index-state + committed map (no user-controlled host/path) |
| T-04-16 | Denial of service | slow/hung poe.ninja | mitigate | 30s reqwest timeout (plan 01); per-type skip-on-failure prevents one stuck type aborting everything |
</threat_model>
