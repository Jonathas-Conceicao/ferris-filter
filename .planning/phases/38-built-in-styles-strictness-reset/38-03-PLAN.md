    - After set_strictness(Comfy) on the fixture set: unchanged, hidden, Recycle, kite, exceptional are == their loaded values; styles_dirty() true; revert_scope(Styles) restores the loaded set exactly
    - Strictness::Custom.hidden() is empty and set_strictness(Custom) changes nothing and returns false
    - reset_styles on a set with edited built-ins and customs: the first nine names equal the default built-in names in default order, each == its default Style, the customs follow in their prior relative order with their ids; strictness() == FlatBroke; styles_at_defaults() true; revert_scope(Styles) undoes it
    - styles_at_defaults(): true on a fresh load of the shipped defaults; false after one switch flip; true on the fixture set only if its built-ins and their order equal the defaults (customs ignored; a custom placed between F and unchanged makes it false)
    - reset_tiers on edited tiers (a changed min, a bad buffer text with an error, and a different unit): entries come back to the default min and unit in the SAME entry order as before, buffers equal format!("{}", min), no errors; tiers_at_defaults() true; dirty_count() > 0 when the applied snapshot differed, including a unit-only difference
    - tiers_at_defaults(): true on a fresh load of the shipped tiers; false after set_tier_text with another value
    - BSTY-03: a temp home with tests/fixtures/seed-styles.json copied as styles.json loads with 12 style names incl.   </behavior>

    `Debug, Clone, Copy, PartialEq, Eq` on `pub enum Strictness { Custom, FlatBroke, Scrounging,
    GettingBy, Comfy, Loaded, DivFarmer }`; `pub const TIER_LETTERS: [&str; 7]` = S..F;
    `Strictness::ALL: [Strictness; 7]` in button order (Custom first); `hidden(self) -> &'static [&'static str]`
    (Custom and FlatBroke empty, Scrounging F, GettingBy E F, Comfy D E F, Loaded C D E F, DivFarmer B C D E F);
    `caption_lines(self) -> &'static [&'static str]` (`Custom`, `Flat`/`Broke`, `Scrounging`,

    texts verbatim (Custom: `Your own mix of shown and hidden tiers. Pick a level to replace it.`;
    levels: line 1 `Hides nothing. Every tier shows.` / `Hides tier F.` / `Hides tiers E and F.` /
    `Hides tiers D to F.` / `Hides tiers C to F.` / `Hides tiers B to F.`, then a blank line and the
    shared note `Affects every rule that uses these tier styles, yours included.`);
    `pub fn strictness_of(set: &StyleSet) -> Strictness`: for each letter resolve
    `set.name_of_id(&StyleSet::builtin_id(letter))`; any absent -> Custom; collect the letters whose
    style `action == StyleAction::Hide`; return the non-Custom level whose `hidden()` equals that
    set, else Custom. Unit tests for every pattern in the behaviour list live here.

    `src/overlay/config_state.rs` (helpers placed beside `edit_style` / `revert_scope`, Claude's
    discretion):
    - `pub fn strictness(&self) -> Strictness` = `strictness_of(&self.styles)`.
    - `pub fn set_strictness(&mut self, level: Strictness) -> bool`: Custom returns false; otherwise
      for each of the seven letters, resolve the name by id (skip an absent id, UI-SPEC choice 8) and
      call the existing `edit_style(name, StyleEdit::Action(Hide if letter in level.hidden() else Show))`;
      return whether any call changed something. No apply_state handling (the app derives it per frame).
    - `pub fn reset_styles(&mut self)`: build a new set with `StyleSet::from_pairs` from the built-in
      entries of `StyleSet::shipped_defaults()` (filter `StyleSet::is_builtin`, default order) followed
      by the pending set's non-built-in entries in their current order (ids kept). Assign it to
      `self.styles`; leave `styles_applied` alone.
    - `pub fn styles_at_defaults(&self) -> bool`: the first N names of the pending set (N = number of
      default built-ins) equal the default built-in names in order and each pending `Style ==` the
      default one.
    - Default tiers: parse `crate::defaults::TIERS_DEFAULT.text` into `Vec<TierEntry>` the same way
      `ConfigState::load` parses tiers (serde + `ValidatedTiers::try_from`), cached in a `OnceLock`.
    - `pub fn reset_tiers(&mut self)`: for each entry of `self.tiers`, find the default entry with the
      same `tier` and copy its `min` and `unit` into it (do NOT replace the Vec: keeps file order and
      the positional comparisons); then `self.resync_buffers()`.
    - `pub fn tiers_at_defaults(&self) -> bool`: every default entry has a pending entry of that tier
      with equal min and unit, its buffer equals `format!("{}", min)`, and the tier errors are empty.
    - Landmine fix in `tiers_dirty_count`: also count an entry whose `unit != base.unit`.
    Tests go in the existing `config_state.rs` tests module using `tempfile::tempdir()` +
    `ConfigState::load(dir.path())` (the module's `loaded()`-style helpers; copy
    `tests/fixtures/seed-styles.json` as `styles.json` where customs are needed); never env vars.
