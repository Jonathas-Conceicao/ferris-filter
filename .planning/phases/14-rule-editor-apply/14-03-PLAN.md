sockets, quality, corrupted — each with its own on/off, each writing through plan 14-01's tested
functions.

"enable toggle + value widget" shape applies to every one of them, including `corrupted` — no
bespoke tri-state control.

    `edit::set_defence(when, Defence::…, ticked)`. Wrap the three in `ui.add_enabled_ui(group_on,
    …)` so they grey out rather than disappear when the group is off — the player can see the
    control exists.

    unticked box means "has none of it", because that asymmetry (`> 0` vs. a literal `0`) is the
    single least-guessable thing in the editor and it is what makes all seven PoE2 armour
    combinations reachable.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| player input in the expanded row → `When` fields → `dynamic.json` | The widest input surface the tool has ever had, but every value is written into an already-typed struct field, never into raw JSON text. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-09 | Tampering | A control producing a store the compiler rejects (an unknown style, a malformed rarity string, an empty `Class` line) | mitigate | The pickers offer only values derived from the loaded `Config` and the closed `RarityOp`/`Rarity` enums; the compact rarity string and the empty-class-collapse are both `edit::`'s job, enforced by the greps forbidding comparator string literals and direct `When` assignment in this file. |
| T-14-10 | Tampering | Presentation code drifting logic out of the tested library layer over time (`PITFALLS.md` §8's failure mode) | mitigate | The `when\.<field> *=` grep criterion fails the plan if any `When` field is assigned outside `edit::`; `grep -c 'edit::'` requires the calls to actually be there. |
| T-14-11 | Denial of Service (local) | A `DragValue` accepting an absurd typed value (negative sockets, quality 10^9) that the emitter then writes into the filter | accept | The `.range(…)` clamps cover the realistic case; PoE2 ignores a condition it cannot satisfy, and a nonsensical threshold makes the rule match nothing rather than corrupting anything. No data loss, self-inflicted, one edit away from a fix. |
| T-14-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this plan. A new dependency would require a blocking human checkpoint before `cargo add`. |
</threat_model>
