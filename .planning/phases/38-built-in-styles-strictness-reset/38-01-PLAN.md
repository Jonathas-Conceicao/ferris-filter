Swap the shipped default styles for the author's nine reworked built-ins without changing what any
existing test or the CLI `generate` oracle sees.

Purpose: BSTY-01 / BSTY-02 and the CONTEXT decision that `generate` is not reworked: today's

read, so `tests/fixtures/seed-universal.filter` stays byte-identical.

bytes, repoint every reader, then swap the root file and fix any straggler the swap exposes. All
stragglers are fixed in this plan so later plans never touch these test files for this reason.

Output: `tests/fixtures/seed-styles.json`, new `styles-default.json`, repointed test readers, new
default-content tests in `src/defaults.rs`, and the manual UI sample case 3 moved off `kite`.
</objective>
