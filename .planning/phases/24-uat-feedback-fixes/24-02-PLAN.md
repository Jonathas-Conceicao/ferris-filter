## Facts found while planning

- `StyleAction` (src/models/config.rs L124) has only `Show` and `Hide`; the CONFIG style editor's
  ACTION control (`config_view.rs` ~L716-728) already offers only those two. So UAT-04's
  "style config offers Show and Hide only" is already true and there is no `Minimal` style JSON to keep
  loading; do NOT add a `Minimal` variant or touch models/emitter (generator out of scope). Record this
  in the SUMMARY. The per-rule control is handled by plan 24-05.
- "Built-in" = `StyleSet::is_builtin(name)`, surfaced as `ConfigState::badges(name).builtin`
  (config_state.rs ~L186-195); `delete_visible` (config_view.rs L173) already hides delete for them.
- `segmented` (config_view.rs L244) is still used by the sound editor (~L875); keep it.
- In egui the last-registered overlapping interact wins the click: the header-row `ui.interact`
  (~L587) is registered after the header widgets, so a switch placed inside the header would lose its
  clicks to the row. Register the switch after that interact, or exclude its rect from the row's.
