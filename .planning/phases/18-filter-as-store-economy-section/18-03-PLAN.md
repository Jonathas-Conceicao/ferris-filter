    - find: 0 markers -> Ok(None); one begin before one end -> Ok(Some(SectionSpan{begin, end})) (0-based indices)
    - find: end only -> EndWithoutBegin{line}; begin only -> BeginWithoutEnd{line}; end before begin -> EndBeforeBegin{begin, end}; two begins -> DuplicateBegin{lines}; two ends -> DuplicateEnd{lines}; all line numbers 1-based in the error
    - find: a marker line placed inside a block's owned range (between header and last body line) -> MarkerInsideBlock{line}
    - find ignores the value part: `#ff:economy-begin anything` and `  #ff:economy-begin` count as markers; `# #ff:economy-begin` (disabled-style text) and `Show # #ff:economy-begin` do not
    - refresh(text, body): bytes before and including the begin line, and from the end line on, are unchanged; the lines between are exactly ["", body lines..., ""] terminated with the begin line's eol; hand-written garbage between the markers is replaced
    - refresh is idempotent on LF, CRLF, BOM and no-final-newline (unterminated end marker) inputs
    - refresh on text with no section -> Err(NoSection); refresh with a body containing an economy-begin/end marker line -> Err(BodyContainsMarker{line}) and no output
    - add(text, body): text without a section gets: (if the last line is unterminated) a terminator using the last terminated line's eol (LF if none); (if text is non-empty) one blank separator line; BEGIN_LINE; ""; body lines; ""; END_LINE (terminated). Eol for new lines = eol of the last terminated line, LF for an empty file. BOM preserved
    - add on text that already has a section -> Err(AlreadyPresent{line}); add on damaged markers -> the find error
    - remove(text): deletes begin..=end inclusive plus one blank line immediately before the begin marker if present; remove on text with no section -> Err(NoSection)
    - remove(add(x, b)) == x for x in: "", LF file, CRLF file, BOM file, file ending in a blank line
    - after add/refresh, re-parsing the result: both marker lines sit in Item::Trivia (not in any block's leading/owned range), and the block count equals blocks(before-section part) + blocks(body)
    - invalid UTF-8 input is impossible at this API (takes &str); a text whose parse fails returns SectionError::Parse
  </behavior>
