In src/safe_write.rs (CONTEXT "Apply and Revert (CONF-04)": validate both files, write both to temp files, then rename both, all or nothing):

1. Extract the persist retry loop from `write_guarded_with` into a private `fn persist_with_retry(temp: NamedTempFile, path: &Path, persist: &mut impl FnMut(..), sleep: &mut impl FnMut(Duration)) -> Result<(), WriteError>` preserving exact behaviour (read-only check, non-retriable stop, MAX_ATTEMPTS, 50 ms doubling backoff). `write_guarded_with` calls it; existing tests must pass unchanged.

2. Add `pub struct Target<'a> { pub path: &'a Path, pub loaded: Option<&'a [u8]>, pub new: &'a [u8] }`.

3. Add `pub enum AllOrNoneError` (thiserror + miette::Diagnostic): `NothingWritten(#[from]-less WriteError)` with Display `{0}` ; `RolledBack { failed: WriteError }` Display `{failed} The other file was restored, so nothing was changed.`; `RollbackFailed { failed: WriteError, unrestored: Vec<PathBuf> }` Display naming each unrestored path: `{failed} {path} could not be restored to its previous contents.` Add `pub fn changed_on_disk_path(&self) -> Option<&str>` returning the path when the inner error is `ChangedOnDisk` (plan 21-04 uses it to raise the outside-edit prompt).

4. Add `pub fn write_all_or_none(targets: &[Target]) -> Result<Vec<WriteOutcome>, AllOrNoneError>` delegating to a private `write_all_or_none_with(targets, persist, sleep)` (same injectable seams as write_guarded_with). Steps in this order (RESEARCH Pattern 1):
   a. For every target: parent dir must exist (else DestinationMissing); re-read current bytes (NotFound = None, other read errors = Unreadable); `current != loaded` → ChangedOnDisk. Nothing touched yet.
   b. Targets with `loaded == Some(new)` are Unchanged and skipped from the rest.
   c. Stage one `NamedTempFile::new_in(parent)` per remaining target with `write_all` + `sync_all`; any failure returns NothingWritten(Unwritable) (dropped temps auto-delete).
   d. Preflight every remaining target that exists: `is_read_only(path)` → ReadOnly; `OpenOptions::new().write(true).open(path)` (no truncate) failing → map with the same retriable/Busy logic as a single attempt (Unwritable/Busy/ReadOnly). Drop the handle.
   e. Persist in input order via `persist_with_retry`. If target k fails after targets 0..k-1 were replaced, roll back each replaced target in reverse: when its `loaded` was Some, write those bytes back through a fresh same-dir temp + `persist_with_retry`; when it was None, `fs::remove_file`. Return RolledBack or RollbackFailed accordingly.
   f. No `.ffbak` is created for these targets (orchestrator decision 2: both files are git-tracked; in-memory rollback is the safety mechanism). Return outcomes with `Written { backup: None }`.

5. Tests use `tempfile::tempdir()` only. Reuse/extend the existing `failing_persist` helper pattern with a call counter to fail the Nth call. The read-only test restores write permission before the tempdir drops.
