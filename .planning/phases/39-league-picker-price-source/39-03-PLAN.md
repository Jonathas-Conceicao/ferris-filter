<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker thread -> UI state | a network result crosses into the frame loop through an mpsc channel |
| saved league (ff-settings.json) -> Sync | the league name the user's sync will request |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-39-08 | Denial of Service | network fetch freezing the overlay | mitigate | `LeagueList::start` runs the work on `std::thread::spawn`; `poll` uses `try_recv` only; a dead worker becomes `Failed` (tested) |
| T-39-09 | Tampering | silent league switch at league end | mitigate | `view` never substitutes another league for a saved one; ended blocks Sync; only `pick_name` of a real entry can lead to a save (tested) |
| T-39-10 | Spoofing | trusting poe.ninja's flapping `indexed` flag | mitigate | the default comes from `default_league` (indexed ignored); grep gate on `indexed` in leagues.rs |
| T-39-11 | Repudiation | a failed fetch shown as "ended" | mitigate | ended only from `Loaded` (tested: Failed/Loading never produce ended) |
</threat_model>
