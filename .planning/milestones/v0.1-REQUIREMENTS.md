# Requirements Archive: v0.1 — Initial Release

**Archived:** 2026-05-28 (milestone shipped)
**Defined:** 2026-05-23
**Outcome:** All 20 v1 requirements delivered across Phases 1-4.

## v1 Requirements (all complete)

### CLI

- [x] **CLI-01**: `ferrisfilter generate` compiles the filter
- [x] **CLI-02**: `ferrisfilter sync` fetches prices
- [x] **CLI-03**: `generate` accepts `--output <path>` (defaults to `universal.filter`)
- [x] **CLI-04**: `sync` accepts combinable `--standard` and `--hc`; neither = current trade league (softcore)
- [x] **CLI-05**: Every subcommand exposes `--help`; binary exits non-zero with a clear message on failure

### Config

- [x] **CFG-01**: Filter policy in `config.json` (renamed from `filter-model.json`): `styles`, build classes, `areaLevelBands`, `alwaysShow`
- [x] **CFG-02**: `generate` validates `config.json` with actionable errors (field path + expected type)
- [x] **CFG-03**: Tier cutoffs in `tiers.json`, validated on load

### Generate

- [x] **GEN-01**: Deterministic compile of `config.json` (+ `tiers.json` + `prices.json`) → byte-identical `universal.filter`
- [x] **GEN-02**: Reproduces the established structure (style tiers, build bands, flask/charm ladder, recycle, currency tiers, gear-hide fallthrough)
- [x] **GEN-03**: Each block carries a model-path comment tag
- [x] **GEN-04**: Uniques (untracked)/gems/jewels/jewellery/quest/waystones/trials/unidentified fall through to game default
- [x] **GEN-05**: Runs without `prices.json` — warns and skips price-tiered rules rather than failing

### Tiering

- [x] **TIER-01**: Derives cross-rates from the first three `prices.json` anchors; converts priced items to chaos
- [x] **TIER-02**: Assigns each priced item a tier per `tiers.json` cutoffs
- [x] **TIER-03**: Price-tier valuable uniques; shared base types resolve to the highest tier; untracked fall through
- [x] **TIER-04**: Aborts with a clear error if a reference currency (Exalt/Chaos/Divine) is missing or zero

### Sync

- [x] **SYNC-01**: Fetches PoE2 economy data from poe.ninja and writes `prices.json`
- [x] **SYNC-02**: `prices.json` is an ordered `item → {exalt, chaos, div}` list (nullable); first three are Exalt/Chaos/Divine
- [x] **SYNC-03**: Includes currency, uniques, and other tracked drops; uncut gems only at level ≥ 18
- [x] **SYNC-04**: Resolves the correct league per flags; missing/empty responses don't corrupt an existing `prices.json`
- [x] **SYNC-05**: Records the fetched league and a timestamp in `prices.json`
