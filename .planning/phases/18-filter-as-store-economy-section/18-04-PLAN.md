<objective>
Rebuild `crate::dynamic` around the filter file as the store: load (with in-memory v0.4
migration), compute the next text for an explicit operation, and write it through the guarded
atomic writer. This is the single headless function set the CLI (18-05) and the overlay (18-06)
both call (D-19).

Decision IDs are defined in 18-01-PLAN.md ("Phase 18 decision index").

`reset_store`, `compile_store`, `write_filter`, ...) is **left in place in this plan** because
`run.rs` and `overlay/app.rs` still call it; 18-07 deletes it once 18-05 and 18-06 have re-pointed
both callers. This keeps the tree compiling after every plan.

Purpose: STORE-01, STORE-03, ECON-03, ECON-04, EDIT-09, EDIT-10 as library behaviour.

longer depends on the JSON store.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user-supplied filter path -> load/apply | any path the CLI or overlay passes |
| file contents -> parser/section ops | foreign, hand-edited, damaged or non-UTF-8 filters |
| other processes -> filter between load and write | game, OneDrive, editors |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-15 | Tampering | apply_file over an externally edited filter | mitigate | write_guarded with the exact load-time bytes; ChangedOnDisk refusal; loaded state unchanged on error |
| T-18-16 | Tampering | lossy decode of a foreign filter | mitigate | NotUtf8 refusal; never lossy-convert (Pitfall 10) |
| T-18-17 | Tampering | typo'd path creating a file | mitigate | Refresh/Remove on an absent file -> FilterNotFound; only AddEconomy creates, and only in an existing directory |
| T-18-18 | Denial of Service | empty section on missing prices | mitigate | economy_body refuses PriceSource::Absent (D-17) |
| T-18-19 | Repudiation | silent v0.4 conversion | mitigate | ApplyReport.migrated lets callers announce the conversion; `.ffbak` keeps the original |
</threat_model>
