<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| network -> ff | GitHub API, sums file and installer bytes are untrusted until hashed |
| %TEMP% folder -> spawn | a per-user folder holds the executable between verify and spawn |
| ff -> installer process | ff executes a downloaded binary |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-41-06 | Tampering | installer download (corrupt, truncated, MITM) | mitigate | streamed ring SHA-256 compared with the release's `SHA256SUMS.txt` line; mismatch deletes the folder; `https_only(true)` on every request and redirect |
| T-41-07 | Tampering / Elevation | compromised release (attacker controls both assets) | accept | a checksum from the same release cannot defeat it (documented in 40-RESEARCH); the URL is pinned to the project repo, the installer is unsigned and per-user (`PrivilegesRequired=lowest`), and the user sees the normal wizard |
| T-41-08 | Tampering | path traversal | mitigate | the file is created at `tempdir.join(installer_name(&v))`; no API string is ever joined onto a path |
| T-41-09 | Denial of Service | oversized bodies | mitigate | caps checked per chunk while streaming (`TooLarge`), asset `size` pre-check, no client-wide timeout but connect 15 s / read 30 s |
| T-41-10 | Information Disclosure / Tampering | temp-dir hygiene | mitigate | `tempfile` creates a fresh unpredictable folder per check under the per-user `%TEMP%`; RAII deletes it on every failure; `sweep_stale` removes only real directories named `FerrisFilter-update-*` older than 24 h and skips symlinks/junctions |
| T-41-11 | Elevation of Privilege | spawn of the downloaded binary | mitigate | `spawn_installer` is only ever given a `ReadyUpdate.installer` path produced by `run_check` after the hash matched (wired in 41-05, re-verified at click); no arguments, no shell string, `Command::new(path)` |
| T-41-12 | Spoofing | update endpoint override | mitigate | URLs are constants; the only test seam is the `UpdateHttp` trait and the `#[cfg(test)]` twin, compiled out of release |
</threat_model>
