## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| disk -> app | ff-state.json in the FerrisFilter folder is local, user-editable, untrusted input |
| app -> poe.ninja / GitHub | outgoing HTTP carrying the user agent string |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-46-01 | Tampering | throttle::load | mitigate | serde with #[serde(default)]; any io/parse/type error -> RequestLog::default(); no panics; league list capped at 200 entries; no path from content used |
| T-46-02 | Denial of Service | RequestLog times | accept | a forged future time counts as expired (is_fresh checks t <= now); a forged recent time only delays the player's own click by at most an hour, local and self-inflicted |
| T-46-03 | Tampering | throttle::save | mitigate | atomic NamedTempFile::new_in(root) + persist (settings::save pattern), only ever root.join("ff-state.json") |
| T-46-04 | Information Disclosure | CLI_USER_AGENT | accept | carries only the version and the already-public repo/contact text USER_AGENT sends today |
| T-46-05 | Repudiation/Spoofing | CLI path throttled or mis-identified | mitigate | isolation_guard source-scan test pins CLI_USER_AGENT in run() and forbids throttle references on the CLI path |
</threat_model>
