## Facts found while planning

- config_view.rs: `COL_VISIBILITY 48`, `COL_NAME 104`, `COL_PREVIEW 120`, `COL_ORDER 64` (~L32-36);
  `cell(ui, salt, width, add)` (~L586) allocates a fixed rect; `styles_table_header(ui, with_order)`
  (~L604) draws the head cells in a `ui.horizontal` inside a `Frame` with `Margin::symmetric(8, 0)`;
  `style_row` (~L753) draws vis/name/preview cells then the `order` cell with `widgets::arrow_button`
  Up then Down, probes `row-up`, `row-down`, `row-order`, and uses `order.left()` as `arrows_left`
  to clip the row click target.
- Test `styles_table_header_and_columns` (~L1861) asserts `hp[1].right() <= ho[0].left() + 1.0` and
  that every `row-order` left equals `head-order` left. `custom_arrows_reorder_and_builtins_have_none`
  (~L2201) clicks the arrows by probe rect.
- rule_list.rs (~L380-400) draws RULES arrows in a `UiBuilder::new().max_rect(inner).layout(
  Layout::right_to_left(Align::Center))` child: Down added first (rightmost), then Up.
- body.rs `colour_combo` (~L2690): `dot(ui, ...)` then `ComboBox::from_id_salt(salt).width(104.0)`;
  each popup row is `ui.horizontal(|ui| { item_spacing.x = 4; dot(..); ui.selectable_label(..) })`.
  The minimap shape combo (~L2756) uses plain `ui.selectable_label` rows and is correct.
- config_view.rs `minimap_editor` (~L1253) and `beam_editor` (~L1293) already call
  `body::colour_combo`, so one fix covers every colour dropdown. `effect_control` (~L2779) and
  `minimap_control` call it too.
- egui 0.36.2 `containers/combo_box.rs` (~L395): `Popup::menu(&button).width(button width)`, then
  `ui.set_min_width(ui.available_width())`, `ScrollArea::vertical().max_height(h)` and inside it
  `wrap_mode = Extend`. Candidate areas for the cause: the menu popup's justified top-down layout
  (selectable labels fill the row width, so the inner width tracks the scroll area's content width
  minus the bar), versus a `ui.horizontal` row whose min width does not shrink to the inner width;
  and `Spacing::scroll` (floating bars, `floating_allocated_width`, `bar_inner_margin`). Read the
  sources at `~/.cargo/registry/src/*/egui-0.36.2/src/containers/{combo_box,scroll_area,popup}.rs`
  and `menu.rs` before changing anything.
