# PoE2 prototype round 2: tabs, style editor, About, status line, minimap atlas

Follow-up to 261015-tz2 after the author's review of `ff-proto`. Look-only prototype on fake
data; `ff` / `src/overlay` / `tests` unchanged.

## Task 1 -- minimap atlas (ff-art + assets)
- Map `art/2dart/minimap/player.dds`: 14 columns of 64px cells. Coloured shape icons come in
  Large/Medium/Small triplets. Circle..Triangle: Blue, Green, Brown, Red, White, Yellow from
  cell 46 (18 cells per shape), then Cyan, Grey, Orange, Pink, Purple from cell 212 (15 per
  shape). Cross, Moon, Raindrop, Kite, Pentagon, UpsideDownHouse: all 11 colours from cell 302
  (33 per shape).
- New manifest `[[atlas]]` entry: source sheet, cell size, sheet columns, and the cell index of
  every output cell (rows = colours, columns = shapes). Output: the Large icons only (the Medium
  and Small cells are the same art scaled down), 12 x 11 cells -> `minimap/icons.png`.
- `git rm` the 4.7 MB `minimap/player.png`; `ff-art dump minimap/player <scratch>` still dumps the
  full sheet for inspection.

## Task 2 -- skin: tabs, minimap texture, new widgets
- `ff_tabs`: lay out on the stone's flat body (left cap + label + start of the right tail),
  tails overlap the next tab like the game, label centred on the body, selected tab drawn last.
- Skin gains `minimap_icons` + a `minimap_uv(shape, colour)` lookup and the 11 fixed game colours.
- New widgets: `ff_switch` (Show / Hide), `ff_pills`, `ff_swatch`, `ff_item_label` (preview),
  `ff_status` (one-line, truncated with "...", full text on hover, coloured by kind).

## Task 3 -- ff-proto
- Four tabs RULES / CONFIG / ECONOMY / ABOUT (`--tab about`).
- CONFIG styles: rows expand in place (one at a time) into the style editor (Show/Hide, preview,
  Text/Border/Background swatch cards, font slider, minimap size pills + colour swatches + shape
  grid of real icons, beam swatches + Temp, sound dropdown + volume). Built-ins locked; customs get
  name field, reorder arrows, delete; "+ Add style". Pre-populated from `styles-default.json`
  (include_str!, parsed in memory, never written).
- ABOUT tab: name, version, description, repo link, credits, disclaimer.
- Status bar: ok / warning / error kinds; REVERT ok, RELOAD error, APPLY long warning.
- `--screenshot` + `--expand-style <name>` to capture the editor.

## Task 4 -- docs + verification
- CLAUDE.md rows, CHANGELOG, README credits; screenshots of every tab, the open editor, a
  truncated status line, saved here; cargo test / fmt / clippy.
