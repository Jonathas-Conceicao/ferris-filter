<interfaces>
Target type (planner decision, per research recommendation; justification: no Default and no
From<[u8;3]> so an opaque colour is never built by accident and the 3-value case lives in exactly one
place, the deserializer; Eq/Hash derived so Phase 44 can key maps by colour):

- `pub struct StyleColour([u8; 4]);` derives Debug, Clone, Copy, PartialEq, Eq, Hash
- `pub const fn new(r, g, b, a) -> Self`, `pub const fn opaque(r, g, b) -> Self`,
  `pub fn from_array(c: [u8; 4]) -> Self`, `pub fn rgba(self) -> [u8; 4]`, `pub fn alpha(self) -> u8`
- Serialize: the inner `[u8; 4]` (compact `[r,g,b,a]` via serde_json::to_string)
- Deserialize: hand-written `de::Visitor` with `visit_seq` (precedent: `Cancelable<T>` in the same
  file), exactly 3 (alpha 255) or 4 u8 elements, `expecting` = "an array of 3 or 4 values (0-255)"
- Do NOT use `#[serde(untagged)]` (loses the dotted error path).
</interfaces>
