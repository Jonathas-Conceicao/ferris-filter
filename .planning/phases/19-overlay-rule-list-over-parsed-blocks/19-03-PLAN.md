<objective>
Library support for the overlay's Apply of an edited document (research gaps G2 and G3, EDIT-08):
`apply_edited` writes caller-supplied edited text with an explicit economy op through the Phase 18
single writer, and `blocking_errors` is the grammar gate ("enabled blocks with grammar errors are
flagged and Apply is refused until they are fixed or disabled").

Orchestrator decisions recorded here:
- OD-1: only **Error**-severity diagnostics inside **enabled** rule blocks block Apply. Warnings
  (unknown keyword, trailing header tokens, which Phase 16 keeps as opaque lines in real foreign
  filters such as NeverSink) are reported to the UI but never refuse Apply.
- OD-2: rules-only Apply is allowed: the economy section is optional, so `EconomyOp::Keep` writes
  a filter with no section.
- OD-3: blocks after the `economy-end` marker are ordinary rules (they are gated and counted like
  any other rule).

Output: new API in `src/dynamic.rs` with hermetic tempdir tests.
</objective>
