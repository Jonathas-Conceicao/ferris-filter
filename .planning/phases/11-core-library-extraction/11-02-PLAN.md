**`src/bin/seed_prices.rs` today** declares five local structs under two "Minimal local mirror"
banners, plus a header comment reading:

> ## Design choice (architecture note)
> This binary duplicates the minimal `CurrencyData` structs locally rather than importing them
> from the crate. Reason: the crate has no `[lib]` target (only `[[bin]]` targets), so
> `use ferrisfilter::...` is not available to other binaries. …

**This reasoning is obsolete.** `Cargo.toml` declares `[lib] name = "ferrisfilter" path =
"src/lib.rs"`, and `[[bin]]` targets in the same package can `use ferrisfilter::…` freely —
`src/main.rs` and `src/bin/ff.rs` already do.

**Field-for-field compatibility (already checked — do not re-verify from scratch):**

| Local struct in seed_prices | Library equivalent | Derives needed | Library has |
|---|---|---|---|
| `CurrencyEntry { tier, class, bases }` | `models::currency::CurrencyEntry` | `Deserialize` | `Debug, Clone, Deserialize, Serialize, PartialEq` ✓ |
| `CurrencyCategory { name, entries }` | `models::currency::CurrencyCategory` | `Deserialize` | same ✓ |
| `CurrencyData { categories }` | `models::currency::CurrencyData` | `Deserialize` | same ✓ |
| `PricesFile { league, fetched_at, items }` | `models::prices::PricesFile` | `Serialize` | `Debug, Deserialize, Serialize` ✓ |
| `PriceItem { name, base_type, class, category, exalt, chaos, div }` | `models::prices::PriceItem` | `Serialize` | `Debug, Deserialize, Serialize` ✓ |

Field names and types match exactly, and both sides already use `#[serde(rename_all =
"camelCase")]`, so the emitted JSON is unchanged.

**Per 11-CONTEXT.md D-11:** if a mismatch does surface, adjust the *binary*, not the library —
do not widen library types for a one-time migration tool. Based on the table above no widening
should be needed; if you find otherwise, stop and report rather than changing `src/models/`.

**`src/models/prices.rs` note:** `PriceItem` has a `div: Option<f64>` field. Confirm the local
mirror's field set is fully covered before deleting it — if the library type has *additional*
fields beyond the seven listed, they must be populated (or defaulted) at every construction site
in `seed_prices`.

   or `PriceItem` needing all seven fields named). Behavior must not change.
4. Keep everything else — `tier_lower_bound`, the seed logic, the output path, the JSON shape —
   exactly as it is. This task removes duplication; it does not touch seeding behavior.
