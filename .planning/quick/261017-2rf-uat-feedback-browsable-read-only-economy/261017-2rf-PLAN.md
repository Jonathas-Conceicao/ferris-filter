quick 261017-0wl (shot nits, review IN-04).

## Task 1: economy rules browsable, read-only; display name FF Economy Section

- `rule_list::show_list`: the expanded row may be an economy block (one row open at a time,
  shared `ListUi::expanded`); `pos_of` also finds `ListEntry::EconomyRule`.
- `draw_economy_row`: the row is clickable and toggles expansion; expanded, it draws the same
  editor body (`body::conditions_group`, `body::style_section`, the Name row only when the block
  has a name) inside a disabled `Ui` (no clicks, no focus, no popups, no keyboard), against a
  throwaway clone of `ListUi` and a throwaway action list (both dropped), and no Section above /
  Duplicate / Delete row. Still no check and no arrows. Quoted lists show every entry in a
  disabled `Ui` (a disabled scroll area cannot scroll), so long BaseType lists stay inspectable.
- Model guard stays: `WorkingFilter::dispatch` refuses any action whose target is a block that
  is not a row (T-32-13).
- Display name: the economy `SectionRow` reads **FF Economy Section** (const
  `ECONOMY_DISPLAY_NAME`); `section::BEGIN_LINE` and `settings::section_key` (economy key) are
  unchanged. ECONOMY_TIP / ECONOMY_LOCKED_STATUS / ECONOMY tab heading name it.
- Tests: expanding an economy row draws the body and emits no action; clicks and key presses
  on every widget rect of the expanded economy body produce no action and leave `ListUi`
  unchanged; Apply after browsing is byte-identical; search still finds economy rules;
  header shows the new name; the banner text in the file is unchanged.
- Screenshot flag `--expand-economy n` (opens the economy section and expands its n-th rule).

## Task 2: tier inputs (ECONOMY tab)

- Tier boxes 88pt (about 8 digits), placed at the value column of the rows above
  (`CONTROL_WIDTH` from the right edge), 8pt gap, then the unit.

## Task 3: style-editor nits

- (a) `/` tiles: the none swatch gets a visible `INPUT_BORDER` frame when unselected, so
  Minimap / Beam / Alert sound `/` tiles look the same on either zebra band.
- (b) colour cards: when `<Label> (none)` does not fit, draw `<Label>` (still dim = none),
  ellipsized if even that does not fit, full text on hover.
- (c) IN-04: `StyleView::minimap_hint` carries the colour / shape of a loaded
  `MinimapIcon -1 <colour> <shape>`; under `/` the pickers show it and leaving `/` uses it
  (size Large), falling back to the remembered value, then White Circle.
