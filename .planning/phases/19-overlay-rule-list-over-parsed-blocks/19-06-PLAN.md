| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-19-21 | Tampering | concurrent external edit | mitigate | ChangedOnDisk sets needs_reload; footer offers only RELOAD/SYNC; RELOAD re-reads and discards edits (copy says so) |

| T-19-23 | Information disclosure | tests | mitigate | Tempdir filters; repo root used read-only for economy inputs; never the real game folder |
| T-19-24 | Tampering | economy section | mitigate | Add/Remove staged in memory; written only by Apply via `filter::section` ops with damage detection; Damaged state disables Apply and economy buttons |
