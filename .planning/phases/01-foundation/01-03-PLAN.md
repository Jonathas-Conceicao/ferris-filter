## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem → tiers/prices/config loaders | Local JSON files (hand-edited or sync-written) parsed and validated |
| user argv → generate | `--output` path and the implicit config.json/tiers.json paths |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-07 | Denial of Service | panic on malformed config.json / tiers.json | mitigate | `load_json` + `load_tiers` return `miette::Result` and propagate with `?`; no `unwrap()`/`expect()` on input. Verified by the missing/malformed integration tests (CFG-02). |
| T-01-08 | Tampering | invalid tier data (missing tier / wrong order) passes silently | mitigate | `ValidatedTiers::try_from` enforces completeness + within-unit ascending, returning a typed error (D-08, CFG-03). |
| T-01-09 | Information Disclosure | error message leaks file contents | accept | miette echoes the offending JSON span by design (that IS the UX, D-03); files are local user-owned policy files, not secrets. Low risk for an offline CLI. |
| T-01-10 | Denial of Service | deeply nested / huge tiers.json or prices.json | accept | serde_json default recursion limit (128); local shallow files per RESEARCH Security Domain. |
</threat_model>
